# 桌面待办悬浮 · 月历任务版

一个常驻桌面角落的透明悬浮挂件。以月历为核心，点日期即可记录当天工作、勾选完成，支持重复任务、到期提醒和 Excel 导入导出。基于 Electron + 原生 HTML/CSS/JS，零前端框架、零第三方运行时依赖（除 Electron 本身）。

## 功能特性

- **月历视图**：年/月下拉快速跳转；鼠标滚轮在日历上滚动即可上下翻月；日历支持「自适应 / 紧凑 / 标准」三档，选中多日或任务较多时自动压缩以显示更多内容。
- **按日记录**：点日期选中，在底部输入回车即存到该日；支持单选、Ctrl/⌘ 逐个多选、Shift 连选，多个日期的任务在下方聚合展示，可直接复制。
- **待办速览**：点顶部计数、日期格数字或面板计数，弹出当天/所选日期的待办列表，点条目可跳回月历对应待办；面板 `‹ ›` 切换当天待办，`↑ ↓` 跨日期循环切换全部待办。
- **重复任务**：指定日一次、每天、每周、每月、每隔 N 天，自动生成未来 60 天任务。
- **到期提醒**：可为任务设时间（文字开头写 `HH:MM`），支持到点/提前提醒与系统通知；未填时间按设定时间提醒。
- **Excel 导入导出**：支持 `.xlsx` / `.csv`，列顺序为「日期、时间、事项、状态、标签」，导出可选全部 / 选中日期 / 指定日期段，导入按「事项 + 日期」自动去重。
- **窗口控制**：置顶、收起为窄条、隐藏到托盘、窗口高度调节，位置与尺寸自动记忆。

## 快速开始

需要 Node.js 18+ 与 npm。

```bash
# 1. 安装 Electron 运行时（约 100MB，仅安装时需要联网）
npm install electron --save-dev

# 2. 启动
npm start
```

Windows 用户也可直接双击 `启动桌面待办悬浮.cmd`（会调用 `node_modules\electron\dist\electron.exe`）。若不想用 npm，可自行下载对应平台的 Electron 解压到 `node_modules/electron/dist/` 后再运行启动脚本。

> 说明：为控制仓库体积，Electron 运行时未随源码提交，请按上述方式本地安装。

## 数据存储

- 任务以 Markdown 形式存放，默认目录为系统「文档/待办悬浮数据/00-收件箱/速记待办.md」。
- 可通过设置环境变量 `TWF_VAULT` 指定任意数据目录（例如指向你的 Obsidian 库）。
- 窗口位置、置顶、收起等状态存在 Electron 的 `userData` 目录下（`widget.json`）；提醒记录在 `reminder-state.json`。

卸载只需删除程序目录；任务数据留在「文档」中，不会因删除程序而丢失。
